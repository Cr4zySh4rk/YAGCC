Set up your DIY guitar controller in the browser

Flash a Raspberry Pi Pico, press each button twice, and play. There's nothing to install and nothing to compile, whichever pins you wired.

Install firmware first

Install the firmware

  1. Pick your board

  2. Enter bootloader mode

    Unplug the board, hold BOOTSEL, plug it back in and let go. A drive called RPI-RP2 or RP2350 appears.

    Already running YAGCC? It can restart itself into this mode. Or hold Star power + Plus while plugging it in.

  3. Copy the firmware

    Drop the file onto that drive. The board restarts as a guitar controller.

    Download firmware
    Coming from Santroller or GP2040-CE?

    Wipe the board first with the flash nuke. It erases old firmware and settings, then drops back into bootloader mode.

    Download flash nuke

  4. Connect

    Click connect and pick YAGCC Guitar Controller. Setup starts right away.

    Console authentication Experimental

    PS4 / PS5 and Xbox One / Series modes need a licensed controller plugged into a USB host port on the guitar. The console's security check is passed through to it, the same way GP2040-CE does it. Not yet tested on a console.

    What to plug in

    • PS4 / PS5: a DualShock 4 (wired), or a USB PS4 authentication dongle.
    • Xbox One / Series: a wired Xbox One / Series controller (Microsoft, PowerA), or a Mayflash / MagicBoots Xbox One adapter.
    Mode changes take effect after a restart.

    Hardware

    Boards, switches, sensors and LEDs you can build a YAGCC guitar with. Buttons go on any free GPIO; setup works out which is which.

    Fake "Pico W" boards. Many cheap boards replace the Raspberry Pi radio with an ESP8285, which only does Wi-Fi. They work fine over USB with the clone firmware but can never do Bluetooth. A genuine Pico W has a metal shield marked "Raspberry Pi".

    Compatibility

    Which mode to use for each console and game, and how well it's tested.

    Consoles that require authentication

    PS4, PS5 and Xbox One / Series only accept licensed controllers. Two setups work without extra hardware:

    • Fortnite Festival in keyboard mode, since keyboards are never asked to authenticate. On Switch, use Switch mode (orange fret).
    • Rock Band 4 on PS4 / PS5 in PS3 Rock Band mode (red fret). The game accepts PS3 guitars as legacy instruments.

    For anything else on those consoles, PS4 / PS5 and Xbox One / Series modes pass the check through to a licensed controller plugged into a USB host port on the guitar (set up on the Modes page). That is experimental and not yet tested on a console.
