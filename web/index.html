Setup

Work through the steps in order. Buttons and whammy are all most guitars need; the rest is optional.

    Tune

    Optional: fine-tune how the guitar feels. Most people never need this page.

    Connect a controller to tune it.

    Button debounce

    Stops one press from counting twice. Presses still register in about 0.2 ms; the time below is how long an input is locked after it changes.

    Shared strum lockout

    Up and down share one window, so a bouncing strum bar can't fire both.

    Whammy

    Invert direction

    Flip it if the bar reads backwards.

    Tilt switch

    Tilt sensors

    Analog tilt sensors, or an I²C accelerometer (LIS3DH, ADXL345, MPU-6050, found automatically). Each sensor works the whammy or presses star power past an angle you set, alongside the whammy bar, the star power button and a tilt switch. A mercury or ball tilt switch is set up in Setup.

    Rumble

    A small vibration motor (a coin or ERM motor) on a free pin, switched by an NPN transistor or logic-level MOSFET with a flyback diode across the motor; never straight from the pin. It follows the rumble games send (XInput, PS4, PS5, original Xbox) and can buzz when star power starts or a note is missed.

    Reset everything

    Puts every setting (buttons, whammy, tuning, lights and modes) back to factory defaults and saves that straight away.

    Steam receiver mode on Windows (experimental)

    Off by default: on Windows the guitar is a normal wired Xbox 360 pad. Turn on to present it as one controller of an Xbox 360 wireless receiver instead, which Steam handles better (a wired pad sharing its USB device with the configurator can trip Steam up). If the guitar stops being recognised on Windows with this on, turn it off.

    Keyboard bindings

    For keyboard mode. They have to match the keys set in Fortnite.

    Console authentication Experimental

    PS4 / PS5 and Xbox One / Series modes need a licensed controller plugged into a USB host port on the guitar. The console's security check is passed through to it, the same way GP2040-CE does it. Not yet tested on a console.

    What to plug in

    • PS4: a DualShock 4 (wired), or a USB PS4 authentication dongle.
    • PS5: a Besavior P5General dongle (PS5 mode; it also signs every report).
    • Xbox One / Series: a wired Xbox One / Series controller (Microsoft, PowerA), or a Mayflash / MagicBoots Xbox One adapter.

    Console ports and Wii Remote Experimental

    Wire the guitar straight into a console's controller port, or let a Pico W be a Wii Remote. These work alongside the USB modes: each one stays quiet until a console talks to it. Ported from Santroller; not yet tested on a console with YAGCC.

    Test

    Press things on the guitar and see what a console would receive. Pick a mode, and change what any input does in it.

    Wiring & hardware

    Boards, switches, sensors and LEDs you can build a YAGCC guitar with. Buttons go on any free GPIO; setup works out which is which.

    Fake "Pico W" boards. Many cheap boards replace the Raspberry Pi radio with an ESP8285, which only does Wi-Fi. They work fine over USB with the clone firmware but can never do Bluetooth. A genuine Pico W has a metal shield marked "Raspberry Pi".

    Compatibility

    Which mode to use for each console and game, and how well it's tested.

    Consoles that require authentication

    PS4, PS5 and Xbox One / Series only accept licensed controllers. Two setups work without extra hardware:

    • Fortnite Festival in keyboard mode, since keyboards are never asked to authenticate. On Switch, use Switch mode (orange fret).
    • Rock Band 4 on PS4 / PS5 in PS3 Rock Band mode (red fret). The game accepts PS3 guitars as legacy instruments.

    For anything else on those consoles, PS4 / PS5 and Xbox One / Series modes pass the check through to a licensed controller plugged into a USB host port on the guitar (set up on the Modes page with Advanced on). That is experimental and not yet tested on a console.
